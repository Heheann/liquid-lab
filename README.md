# 💧 液體研究所：液體搬家大挑戰

給國中特教班與資源班使用的互動自然科教材，適合 Windows 電腦、Chrome／Edge 與大型觸控電子白板。

## 內容

- 4 個研究關卡，內建完整 30 題題庫：Level 1：8 題、Level 2：8 題、Level 3：7 題、Level 4：7 題。
- 每關可抽 3／4／5 題或全部；同一局不重複，Level 4 可由教師 ON／OFF。
- Level 2 採「選目的容器 → 先預測 → 真正倒液體動畫 → 再回答觀察題」。
- 答錯提供兩階段提示，第三次顯示概念與答案，但仍需點選正確答案才能繼續。
- 結果頁提供四項能力統計與逐題研究紀錄。
- 教師工作區支援研究室、題數、難度、動畫速度、題目啟用狀態、編輯、新增、刪除、圖片更換、匯入與匯出。
- 使用 IndexedDB 保存題庫、設定、未完成研究與學習紀錄。
- 學生操作不需要鍵盤；主要互動支援滑鼠、手指與觸控筆 Pointer Events，拖曳另有點選替代操作。

## 開啟

已安裝 Node.js 的電腦可雙擊「開啟液體研究所.cmd」，或在專案資料夾執行：

```text
npm install
npm run dev
```

正式建置：

```text
npm run build
npm run preview
```

也可以直接開啟 `dist` 的本機預覽伺服器；不要直接雙擊 `dist/index.html`，因為本機保存與離線功能需要透過網址使用。

## 驗收

```text
npm test
npm run build
```

教師資料請定期從「教師設定 → 匯入／匯出」匯出備份。清除瀏覽器網站資料、使用無痕模式或更換瀏覽器，可能會清除本機題庫與紀錄。
